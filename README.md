# craft-diagrams notes

Working notes, plan, PR drafts and helper scripts for diagramming in FigCraft Boards
(Mermaid import, layered layout, connector routing, VSDX export/import, shape libraries).
The project is paused; nothing here has been posted upstream.

Code lives on branches in the forks:
- Satal/figcraft: `boards-vsdx` (everything), `boards-diagram` (Mermaid, layout, routing, UI)
- Satal/craft-libs: `graph-layout`, `mermaid`, `vsdx` (new crates)

Contents: `PLAN.md`, `research/` (specs written from public docs, standards audit, linked
requests, PR and issue drafts), `tools/` (Docker cargo wrapper, web build, mermaid2vsdx CLI).
The MS-VSDX PDF and build logs are not included.
